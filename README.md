# Python Task Management API

A production-style Task Management REST API built using Python and Flask.

## Project Overview

This project provides a simple REST API for managing tasks. Users can create, view, update, and delete tasks through HTTP requests.

The project includes input validation, error handling, dependency management, and complete setup documentation.

## Features

- Create tasks
- View all tasks
- Update tasks
- Delete tasks
- Input validation
- Error handling
- JSON responses
- Clean project structure
- Dependency management using requirements.txt

## Technologies Used

- Python
- Flask
- REST API
- JSON
- Git and GitHub
